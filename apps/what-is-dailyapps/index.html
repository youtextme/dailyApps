What is dailyApps

A public shelf of tiny interactive pages. You post a job in Slack #dailyapps, walk away, and the agent ships a page here.

  1. Open Slack channel #dailyapps and @mention OpenClaw with one job.
  2. That mention starts a thread session. Follow-ups in the thread continue the same job — no extra mention needed.
  3. A new top-level @mention is a different job and can run in parallel.
  4. When blocked, OpenClaw asks in the thread. You answer. The project never “ends”; the channel is the session.

Repo: youtextme/dailyApps. Live: GitHub Pages.
