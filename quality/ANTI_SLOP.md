# Anti-slop checklist (code-enforced)

Enforced by `tireless.dailyapps.quality_gate`:

- No Inter / Roboto as primary font
- No purple/indigo gradient hero aesthetics
- No #F4F1EA cream default
- Must be interactive (button/input + handler)
- Must include viewport, doctype, heading
- Images need alt text
- Shipping bar: customer would rate 5 stars — thin stubs fail `too_thin`
